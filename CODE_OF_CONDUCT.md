# Code of conduct

## The short version

Be someone people want to work with. Assume the other person is trying to help.

## What is expected

- **Argue about the work, not the person.** "This breaks the cost constraint because…" is
  the right shape. Anything about the contributor rather than the contribution is not.
- **Say when you are unsure.** "I think this is wrong but I might be missing something" is
  a strength here, not a weakness. This repository's own documentation records the times
  its author asserted a thing without checking, because that is more useful than pretending
  it did not happen.
- **Take a correction plainly.** If someone shows your claim is wrong, the useful response
  is to fix it and move on. No apology tour required.
- **Assume good faith about the tools.** A disclosed AI-assisted contribution is welcome
  here. Somebody who discloses it and then gets lectured has been punished for honesty,
  and the next person will simply not disclose.

## What is not

Harassment, personal attacks, demeaning comments, unwelcome attention, publishing private
information, and sustained disruption. Discrimination on any basis — including but not
limited to gender, gender identity, sexual orientation, disability, physical appearance,
body size, race, ethnicity, age, religion or nationality.

Body size and appearance deserve a specific mention, because this is a fitness project.
People arrive here at every stage of every kind of body. Remarks about anyone's — including
approving ones, including your own framed as a comparison — are not welcome.

## Scope

Issues, pull requests, commit messages, code comments, and any project space.

## Reporting

Email **ashwinraghav@gmail.com**. Reports are read by the project maintainer and kept
confidential. If your report concerns the maintainer, say so — you are entitled to be
uncomfortable about that, and a public issue is also a legitimate option.

There is no committee to appeal to. This is a small project with one maintainer, and
pretending otherwise would be theatre.

## Consequences

In rough order: a private word, a public correction, having a comment removed, a temporary
block, a permanent one. Which one depends on what happened and whether it continues.
