# Published costs

The free-forever claim is an assertion about running costs, so the bills are published (ADR-0020).

A monthly GCP billing export lands here, scrubbed of account identifiers. Cost regressions are
publicly visible, which is the point — it is a standing incentive to keep rule 2 of the
constitution.

**Phase 0 target: $0/month.** There is no backend at all.
