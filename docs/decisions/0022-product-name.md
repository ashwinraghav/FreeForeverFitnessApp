# ADR-0022: Product name: TheFreeForeverFitnessApp

- **Status:** Accepted
- **Date:** 2026-08-28
- **Decided by:** Project owner, with Claude Opus 5 (session 60f2e23f)

## Context

The name sets the repository, domain, package scope and wordmark, and renaming after launch is genuinely painful. Candidate names in the brandable direction (Freeweight, Chalkline, Ironlog) were considered.

## Decision

**TheFreeForeverFitnessApp.** The npm scope is `@freeforever/*` so imports stay readable; short forms 'Free Forever' and 'FFF' exist for tight UI spaces.

## Consequences

The name states the entire positioning and cannot be quietly abandoned — a product called this cannot introduce a paid tier without the name itself becoming the indictment. That constraint is a feature, and reinforces ADR-0001. Cost: long for a wordmark, which the blueprint direction handles as a stacked technical label plate rather than a single line.

## Alternatives considered

Brandable alternatives were more elegant as marks and weaker as commitments. Chosen deliberately by the project owner.
